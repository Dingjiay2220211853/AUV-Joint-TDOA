# Cyclic relay Joint TDOA for underwater swarms

扩散式水下集群循环中继联合时差定位的复现代码。Includes the 8-event Joint TDOA factor, shared timestamp error states, source-only relay shadow trajectories, and the fixed-budget comparison against conventional dual-master TDOA.

The manuscript compares `D-only` and `J-RR` in 1,000 paired Monte Carlo trials. Each method uses 200 acoustic transmissions per trial. The archived runner also evaluates three other relay orders (`J-D1`, `J-D2`, `J-D3`). The five schedules contribute to the common event timeline used to sample odometry and timestamp noise. Keep the full schedule set to reproduce the same realizations for the two manuscript methods.

## Install

From the repository root, use the tested Conda environment. See [environment details](ENVIRONMENT.md) for the Windows GTSAM build and dependencies.

```powershell
conda env create -f environment.yml
conda activate joint-tdoa
cd GTSAM_v2
```

## Run the experiment

Run one complete 200 s trial to check the installation.

```powershell
python -u -m experiments.master_follower_paper.formal_experiment_6_directional_joint_schedules --mode smoke --start-seed 1 --seed-count 1 --workers 1 --output experiments/master_follower_paper/results/smoke
```

Run and analyze the 1,000 paired trials from the same directory.

```powershell
python -u -m experiments.master_follower_paper.formal_experiment_6_directional_joint_schedules --mode formal --start-seed 1 --seed-count 1000 --workers 12
python -u experiments/master_follower_paper/process_directional_joint_schedule_validation.py --output experiments/master_follower_paper/results/formal_directional_joint_schedules_phi15_beta10_anchor5_seed_1_1000 --start-seed 1 --seed-count 1000 --bootstrap-samples 10000
```

Run the analysis directly as a script, as shown above. You can use a separate environment with NumPy, pandas and Matplotlib for analysis and plots.

The runner checkpoints each completed seed. Restart with the same output directory and configuration to resume. The analysis produces method- and follower-level metrics, paired confidence intervals, and figures.

## Check the published results

The [result tables and frozen configuration](GTSAM_v2/experiments/master_follower_paper/published_results/README.md) contain the original aggregate values. Select `D-only` and `J-RR` in the method tables and `candidate_id=J-RR`, `reference_id=D-only` in the comparison tables for the manuscript results. The simulation inputs and raw outputs are generated by the commands above.

The acoustic factors live in `GTSAM_v2/factors/`. The graph, communication data types and preintegration live in `GTSAM_v2/estimator/`. The scenario, fixed schedules, experiment runner and analysis live in `GTSAM_v2/experiments/master_follower_paper/`.
